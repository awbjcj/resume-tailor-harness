The CLI embeds the same Python service layer: its integration and file-access edges are omitted to keep the view readable. The dashed grouping associates the API with its active workspace; it is not a network or deployment boundary. Local mode selects the default workspace; hosted mode authenticates and resolves a user workspace. Docker serves the built SPA from the API image. Background runs are in-process, not a separate queue service.
