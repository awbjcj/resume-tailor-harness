# Reusable design artifacts

**Teal & Ink** extracts Résumé Tailor's teal/ink workspace style into an
independent kit for other projects.

- [Open the offline interactive preview](teal-ink/preview.html)
- [Read the kit's guide](teal-ink/README.md)
- [Use the agent design brief](teal-ink/DESIGN-BRIEF.md)
- [Download the complete versioned ZIP](teal-ink-design-system-v1.0.0.zip)

The kit includes three theme presets, three-layer design tokens, scoped CSS
components, React/Tailwind adapters, adoption/refactoring guidance, source
provenance, and verification evidence. Copy or extract the full `teal-ink/`
directory to preserve relative paths. The source application's runtime is
independent of this artifact.
